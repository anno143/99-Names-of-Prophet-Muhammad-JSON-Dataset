# Translation & Description Review

A review of every entry in `99_Names_Of_Prophet_Muhammad.json` for translation and description problems. It also adds a `references` field showing where each name, or the wording it comes from, appears in the Quran or hadith.

## 2. Issues noted but not changed

These are judgement calls or problems in the source list. Changing them would mean departing from the source.

| # | Name | Note |

| 2 | Aḥmad | The English "Most Commendable" is passive (most praised), but the Urdu "سب سے زیادہ حمد کرنے والا" is active (most praising). Both readings are valid, but the two languages disagree. |
| 6 / 77 | ʿĀqib / Ākhir | The meanings overlap ("The Last"). |
| 15 | Shāfī | Means "Healer". Many lists have **Shāfiʿ** (شافع, "Intercessor") instead, and that name is supported by hadith (Muslim 2278). Check the source spelling. |

## 3. References

Each entry now has a `references` array. Each reference has:

- `type`: `quran`, `hadith` or `sirah`
- `source`: surah name and verse, or hadith collection and number
- `text`: a short Arabic excerpt, without vowel marks (optional)
- `note`: context, such as where a reading is only an interpretation or a hadith is graded weak (optional)

Hadith numbers follow the common sunnah.com / Fuad ʿAbd al-Bāqī numbering.

70 of the 99 names have at least one reference. The other 29 (e.g. Ḥāmid, Shāfī, Tihāmī, Matīn, Ṭayyib, Qarīb, Shahīr) are descriptive titles found in traditional name lists, and no direct Quran or hadith wording was found for them. Their `references` array is left empty instead of being filled with weak or unrelated citations.

Some references support the **meaning** rather than the exact **wording**. For example, 21:107 is given for Rasūl ar-Raḥmah. In those cases the `note` field says so.
